# Хроники Эйрвальда 3.3.2

## Исправления
- Исправлена недоступность кнопки «Прожить год»: теперь год можно завершить в любой момент, даже если остались неиспользованные действия.
- Неиспользованные действия при досрочном завершении года теряются, а это отражается в хронике.
- Подсказка рядом с кнопкой объясняет, что год можно завершить досрочно.
- Сохранены баланс рас, наследование, возрастные ограничения и остальные исправления версии 3.3.1.

## Запуск
Откройте `index.html` в браузере или опубликуйте папку `chronicles_of_eyrval` через GitHub Pages. Сохранение хранится в localStorage браузера.
