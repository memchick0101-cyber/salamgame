# Хроники Эйрвальда 3.3.0

## Что нового
- Перебалансированы стартовые расовые предрасположенности: эльф стал чуть менее универсальным, дварф и орк сохранили физическую специализацию, штрафы фейри смягчены.
- Удача теперь учитывается в боевой мощи, рейтинге персонажа и шансах гильдейских испытаний; вклад маны в боевой рейтинг снижен, чтобы магические расы не получали чрезмерное двойное преимущество.
- Родовой дар фейри усилен: +2–3 удачи, 45% шанс найти 20–40 золота, иначе восстановление 20 маны.
- Добавлены умеренные расовые особенности взросления и старения: долголетие эльфов, стойкость дварфов, ранний физический расцвет орков, рост магического потенциала фейри.
- Исправлено наследование: партнёр имеет собственную расу и расовые характеристики; ребёнок наследует расу одного из родителей (50/50), а его характеристики рассчитываются с учётом предрасположенностей обоих родителей и расы ребёнка.
- Исправлены возрастные ограничения действий: интерфейс и обработчик используют одну таблицу минимального возраста. Охота доступна с 10 лет, подвиги и гильдия — с 14, отношения — с 16.
- Исправлена загрузка сохранений с нулём оставшихся действий: теперь `0` не превращается ошибочно в 7.
- Исправлено отображение чемпиона после победы: занятое игроком место больше не помечается как повторно побеждённый соперник и не вызывает бесконечные повторные вызовы.

## Запуск
Откройте `index.html` в браузере или опубликуйте папку `chronicles_of_eyrval` через GitHub Pages. Сохранение хранится в localStorage браузера.
